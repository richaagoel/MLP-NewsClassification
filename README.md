# MLP-NewsClassification

In this project, I independently built an end-to-end text classification system using the News Category Dataset from Kaggle. I performed comprehensive NLP preprocessing, including tokenization, stopword removal, stemming, and lemmatization using NLTK. Word embeddings were generated using Word2Vec from Gensim to capture semantic relationships between words. I designed and trained a Multilayer Perceptron (MLP) neural network using TensorFlow/Keras to classify news headlines into multiple categories. The model achieved strong accuracy on unseen test data, demonstrating effective feature extraction and deep learning application in natural language processing tasks. This project highlights my ability to handle real-world text data and deploy machine learning pipelines independently.
